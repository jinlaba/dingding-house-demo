# 房屋托管运营驾驶舱 · 作品演示

一套面向**房屋托管（二房东）行业**的经营分析驾驶舱，展示从数仓建模到可视化呈现的完整链路：
把分散在收房、出房、财务、资金各环节的流水，收敛成「在托规模 → 出租率 → 收支 → 资金 → 利润 → 组织对比」六层指标体系。

- **在线查看**：<https://jinlaba.github.io/dingding-house-demo/>
- **形态**：单文件自包含 HTML（ECharts 内联，零依赖、可离线双击打开）

---

## 这是合成数据，不是任何企业的报表

本看板是**个人作品演示**。页面上的每一个数字，都经过统一变换后重新生成，**无法反推任何真实企业的规模、利润或现金流**。

| 变换项 | 处理口径 |
|---|---|
| 时间轴 | 整体平移，演示期为虚构编号（非真实经营期） |
| 规模类（在托套数、收房、出房、退房、房源数、凭证笔数） | 统一系数缩放 + 逐期确定性扰动 |
| 金额类（收入、支出、净利、押金池、剩余价值） | 统一系数缩放 + 逐期确定性扰动 |
| 单房类指标（单房月租差、单房月净利、单房全周期利润、单房维修费） | 按金额/套数比例联动缩放，保证与总量自洽 |
| 比率类（出租率、空置损失占比、毛利率、净利率） | 小幅扰动，保留行业合理区间 |
| 组织架构 | 代号化（区域A～M），门店编号全部虚构，门店数量已重排 |
| 企业与系统信息 | 公司名、品牌、logo、数据库名、表名、视图名、快照日期全部剔除 |
| 派生字段 | 缩放后一律重算，保证看板内部不出现自相矛盾 |

> 变换系数与扰动种子固定在生成脚本里，同一份源数据每次生成的结果完全一致（可复现），
> 但正向变换不可逆 —— 拿到演示数据也推不回原始数据。

**刻意留空的部分**：财务报表（利润表／资产负债表／现金流量表）不提供数据。
三表联动渲染能力在页面上可见（含本月数／本年累计切换），但填入任何数字都会构成虚构财报，
因此该模块只说明取数方式，不给数。

## 看板能力

| 视图 | 内容 |
|---|---|
| **总览** | 在托房源趋势、月度净收支、出租率趋势、收出退吞吐 + 9 个核心 KPI（含环比） |
| **运营监控** | 收出退明细、业主退房 vs 当月收房（快照倒推口径）、收房类型结构、出租率对比、空置损失、违约退房趋势 |
| **财务报表** | 三表联动框架（本月数／本年累计切换），数据留空 |
| **利润与价值** | 已实现利润、剩余价值（含倒推测算口径）、租差分布、类型利润、单房全周期利润 |
| **组织透视** | 10 维度组织对比（收退比、单房月租差、单房月净利、单房全周期利润、单房维修费、空置损失占比），以总公司为基准线 |
| **数据说明** | 每个指标的数据来源与计算口径，给非财务背景的人看 |

## 几个可以聊的方法论细节

- **快照倒推**：业主退房无历史流水，按最新快照的业主租期到期日倒推历史月，越近的月份越准；
  收房录入滞后时自动回退到上一完整月，避免图表出现假性塌陷。
- **双口径分离**：收房按业主口径、退房按租客口径，两者不混算 —— 混算会系统性高估净增长。
- **剩余价值兜底**：报表缺失的房源，用「租差 × 剩余租期」倒推，并单独标注倒推套数占比，不拿估算值冒充实测值。
- **组织基准对比**：各区域不与"平均值"比，而与企业整体基准比，红虚线标基准，一眼看出谁在拖后腿。
- **口径一致性优先**：净额、已实现利润等字段在原系统里就是独立口径（不等于简单加减），
  缩放时按同一系数平移而不重算，保证形态与相对关系不变。

## 技术形态

- 纯静态单文件 HTML，ECharts 5.5 内联（base64），无外链、无 CDN、可离线
- 数据以 `const DATA` 内嵌，模块化结构（M0 维度 / M1 规模 / M2 出租率 / M3 收支 / M4 资金 / M5 财务 / M6 利润 / M8 说明）
- 生成链路：数仓视图层 → 取数模块 → 口径校验 → 脱敏合成 → 模板注入（管道代码属本地资产，不随演示版发布）
